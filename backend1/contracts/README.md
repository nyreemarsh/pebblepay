# Neo Smart Contracts

This directory contains generated Neo smart contracts in Python format.

Contracts are generated by the `NeoContractGeneratorAgent` and can be compiled using the Boa compiler.

## Usage

1. Generate a contract via the API: `POST /api/neo/generate_contract`
2. Compile the contract: `POST /api/neo/compile_contract`
3. Generated files:
   - `{contract_name}.py` - Python source code
   - `{contract_name}.nef` - Compiled Neo executable format
   - `{contract_name}.manifest.json` - Contract manifest

## Example Contract Spec

```json
{
  "contract_name": "EscrowContract",
  "actions": [
    {
      "type": "store_value",
      "key": "sender",
      "value_type": "UInt160"
    },
    {
      "type": "store_value",
      "key": "recipient",
      "value_type": "UInt160"
    },
    {
      "type": "store_value",
      "key": "amount",
      "value_type": "int"
    },
    {
      "type": "release_payment",
      "from": "sender",
      "to": "recipient",
      "amount_key": "amount"
    }
  ]
}
```
